        已保存的令牌

        只需 Gist 权限。令牌只保存在此浏览器的本地存储里，不会写进仓库或页面。不要在教室或公用电脑上粘贴令牌：它会一直留在那台电脑的浏览器里，直到你点「清除令牌」。

        只存在此浏览器，推送时写进同步记录，方便在下面的历史里认出是哪台设备。

        同步历史与撤销

        GitHub 会为 Gist 保留每次同步的版本。恢复会把所有章节和课表改回那一刻的状态，并作为一次新的同步推送；之后也可以再恢复回来。

          它有多「私密」？

          进度存在你账号下的 secret Gist：不会出现在你的公开 Gist 列表和搜索结果里，但它不是私有的，拿到地址的人不用登录就能查看。Gist 地址写在本站公开的 js/sync-config.js 里，所以请把它当作「半公开」：只放学习进度，不放任何隐私。

          如何创建令牌？
          1. Fine-grained（推荐）：打开 新建 fine-grained token，设置过期时间，在 Account permissions 中把 Gists 设为 Read and write，其他都不选。
          2. Classic：打开 新建 classic token，只勾选 gist。注意两种令牌都能读写你账号下的所有 Gist。
          3. Mac 和 Windows 各粘贴一次，之后打开页面自动拉取、改动后自动推送。令牌过期后重新粘贴即可。
